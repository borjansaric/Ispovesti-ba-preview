# Ispovesti.ba — izolovani preview

Ovaj repozitorijum služi isključivo za pregled i provjeru izgleda testne verzije. Ne povezuje se sa Supabase produkcijom, testnim API-jem, chat serverom, CAPTCHA servisom niti naplatom. Ispovijesti i komentari u ovom pregledu čuvaju se samo u lokalnom pregledniku.

Glavni sajt i njegov repozitorijum nisu dio ovog deploymenta.
